# Historical Archive

Files here preserve superseded plans, closed task logs, and earlier protocol drafts. They are retained for provenance and must not be treated as current implementation instructions. Current authority is listed in [`../README.md`](../README.md).

## Superseded Plans

[`superseded_plans/`](superseded_plans/) contains the V1 bottleneck/Exact-DP design and the earlier program assessment/plan. Later research objectives and actual implementation status are in `../research_positioning.md` and `../program_status_and_design.md`.

## Root Logs

[`root_logs/`](root_logs/) contains the former root `task_plan.md`, `progress.md`, and `findings.md`. These records are retained intact as historical logs and are no longer task entry points.

## Earlier Archive Material

The other files in this directory preserve earlier dataset, R3, manifest, and pilot planning snapshots. For current data status, read [`../../data/README.md`](../../data/README.md). The prior statement that v0.3/P1 was the unique current implementation baseline is withdrawn.
